Install Term Here

Gives webshell access to your computer's files: cat file:///etc/hosts, /host/…. It also adds a real terminal (Alt+T) on any page.

term-here.zip SHA256SUMS

Extension ID ipldffceopngiolfclkimmjkbgapjnfp. Linux and macOS, Chrome, Edge, Brave, Chromium or Vivaldi, with python3.

A web page can't read your files by itself. Browsers block that. So there are two pieces: the browser extension, and a small helper program that the extension talks to. The helper runs as your user. Both are needed.

1. Install the helper

unzip term-here.zip
cd term-here
./install.sh

Registers two native-messaging helpers (host/term_here_fs.py for files, host/term_here_host.py for the terminal) with every Chromium-based browser it finds. Keep the folder: the browser runs the helpers from it. Undo with ./install.sh --uninstall.

2. Add the extension

Open chrome://extensions, turn on Developer mode, click Load unpacked, and choose term-here/extension.

3. Allow webshell

Open webshell. Term Here asks once whether this site may access your files. Click Allow. The header then shows Host files: /host · file:///. You can revoke access in the extension's options.

Opening webshell from a local copy (file://)? Also enable Allow access to file URLs on Term Here's details page.

About the .crx

Don't drag term-here.crx into Chrome. It isn't from the Chrome Web Store, so Chrome rejects it with CRX_REQUIRED_PROOF_MISSING on every OS. Use Load unpacked above.

The .crx is for managed browsers. Chrome only installs self-hosted extensions through admin policy. On Linux, as root, create /etc/opt/chrome/policies/managed/term-here.json (Chromium: /etc/chromium/policies/managed/):

{ "ExtensionInstallForcelist": ["ipldffceopngiolfclkimmjkbgapjnfp;https://caselight.io/shell/updates.xml"] }

Chrome then installs it from updates.xml and keeps it updated. On Windows and macOS this policy only applies to managed devices (Group Policy / configuration profile). You still need step 1 for the helper.
